# 🤖 Breach Bot - 2019 Facebook Data Breach Explorer

Breach Bot is an interactive, terminal-based Python chatbot designed to educate users about the massive 2019 Facebook Data Breach. This project was developed as part of the **Girls Who Code Summer Pathways Program** and uploaded to GitHub to showcase interactive historical analysis using code.

The bot leads users through the logistics of the breach, evaluates the organization's response, and shares a structured reflection utilizing cybersecurity frameworks.

---

## 🚀 Features

*   **Interactive Conversation:** Welcomes users by name and calculates exactly how many years have passed since the 2019 breach based on the current year.
*   **Two-Part Educational Menu:** 
    1.  **Breach Facts:** Covers explicit breach details and the resulting legal/financial responses from Facebook.
    2.  **Developer Reflection:** Features a personalized analysis tying the breach back to the **CIA Triad**, an evaluation of Facebook's actions, and actionable advice for victims.
*   **Terminal-Optimized:** Designed with custom loop prompts and input breaks to keep users engaged directly in the command line.

## 🏃 How to Run the Project in VS Code

Follow these simple steps to start chatting with Breach Bot:

1. **Open the Project Folder:** Launch VS Code, go to `File > Open Folder...`, and select the folder containing this project.
2. **Open the Script:** Click on the `breach_bot.py` (or your specific script name) file in the sidebar to display the code.
3. **Run the Code:** 
   * Click the **Play Button** (Run Python File) in the top-right corner of the VS Code window.
   * *Alternatively:* Open a built-in terminal (`Ctrl + \``) and type:
     ```bash
     python breach_bot.py
     ```
4. **Interact:** Click inside the terminal panel at the bottom of your screen where the prompt appears, type your answers, and press **Enter**!
